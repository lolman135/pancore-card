# PANCORE — фронтенд

Статический сайт без сборки: три HTML-страницы, один CSS, ES-модули.
Никакого npm — открывается любым статическим сервером; в проде отдаётся
nginx/Netlify/любой статикой или бэкендом через `StaticFiles`.

```
frontend/
├── index.html            главная: герой, о компании, направления, производство, преимущества, география (карта), ассортимент, контакты + форма
├── production.html       производство: флагман «безшпульний звій G.657.A2» (паспорт с ползунком длины, OTDR-график,
│                         польовий корпус, Sky/Ground station), досье линий (композиты, литьё, SMT), документы
├── products.html         ассортимент: основные позиции со схемой и назначением + остальное (названия, марки), боковая навигация, фильтры,
│                         ключевые параметры на карточке, шухляда спецификации (#item-NNN), сравнение до 3
├── css/style.css         дизайн-система (токены в :root) — общая с главной, ради внутренних страниц не менять
├── css/pages.css         стили только production.html и products.html (главная его не подключает)
├── js/sketches.js        векторные эскизы изделий в чертёжном стиле (звій, корпус, sky/ground, пропеллер, лист, труба, SMT)
├── js/production.js      паспорт звою, график OTDR (1310/1550 нм), переключатель пропеллеров 10″/15″, навигация досье
├── js/data/own.js        ДАННЫЕ: собственное производство (звій 901, пропеллеры 902/903) со спецификациями
├── js/site.js            общая логика: шапка, меню, появление блоков, WebGL-фон, карта, форма → API
├── js/env.js             ГЕНЕРИРУЕТСЯ из .env: адрес бэкенда (`backend/scripts/gen_frontend_env.py`)
├── js/env.docker.js      версия env.js для compose: пустой API_BASE (тот же origin, что и nginx)
├── nginx.conf.template   конфиг nginx для compose: статика + прокси /api/ на бэкенд
├── js/mesh.js            WebGL-поле граней (three.js, свои шейдеры) — ключевой визуальный элемент
├── js/worldmap.js        карта мира: точечный суходол + анимированные маршруты
├── js/products.js        логика страницы ассортимента (аккордеон со спецификацией)
├── js/data/products.js   ДАННЫЕ: MAIN (блоки с визуалом и назначением) и OTHER (название + марка по категориям)
├── js/data/specs.js      ДАННЫЕ: спецификации позиций (см. ниже)
├── js/data/worldmap.js   ДАННЫЕ: точки карты (path) и координаты узлов
└── assets/               logo.svg, favicon.svg, img/*.webp (фото производства)
```

Язык сайта — украинский. Дизайн: тёмный графит + одна сигнальная красная,
триангулированная сетка на фоне (референс владельца), шрифты Unbounded / Manrope /
JetBrains Mono / Michroma (Google Fonts). three.js подгружается с jsDelivr через import map.

## Локальный запуск

Фронт — любой статический сервер из папки `frontend/`:

```bash
py -m http.server 8090 --bind 127.0.0.1
```

Бэк — из папки `backend/`:

```bash
py -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe main.py          # host/port берутся из .env в корне репозитория
```

### Адрес бэкенда для фронта

Хост и порт лежат в корневом `.env` (`BACKEND_HOST`, `BACKEND_PORT`). Браузер `.env`
прочитать не может, поэтому адрес генерируется в `js/env.js`:

```bash
py backend/scripts/gen_frontend_env.py    # → frontend/js/env.js: export const API_BASE = '…'
```

Запускать после каждой правки `BACKEND_HOST` / `BACKEND_PORT`. Скрипт берёт значения через
`get_settings()`, так что источник правды один, и подменяет адрес привязки `0.0.0.0` на
`127.0.0.1` — на `0.0.0.0` браузер не ходит.

Приоритет адреса в `site.js`: непустой `<meta name="api-base">` → `API_BASE` из `js/env.js`
→ пусто (тот же origin). CORS у бэка по умолчанию `*`.

## Запуск через Docker (nginx + бэкенд)

Из корня репозитория:

```bash
docker compose up -d --build      # → http://127.0.0.1:${NGINX_PORT}
docker compose down
```

`compose.yaml` поднимает два сервиса в сети `inner-network`:

- `backend` — образ из `backend/Dockerfile`, наружу **не** публикуется, слушает `BACKEND_HOST:BACKEND_PORT` из `.env`;
- `nginx` — `nginx:alpine`, публикует `NGINX_PORT:80`, монтирует папку `frontend/` в `/usr/share/nginx/html`
  только на чтение и отдаёт её как статику.

Адрес бэкенда в конфиг попадает из `.env`: `nginx.conf.template` лежит в
`/etc/nginx/templates/`, и штатный entrypoint образа прогоняет через него `envsubst`,
подставляя `${BACKEND_PORT}` (`NGINX_ENVSUBST_FILTER` ограничивает подстановку одной этой
переменной, чтобы не задеть переменные самого nginx). Хост — имя сервиса `backend`,
резолвится встроенным DNS Docker (`resolver 127.0.0.11`); адрес взят в переменную
`$backend_url`, поэтому nginx стартует, даже если бэкенд ещё поднимается.

Origin у фронта и API общий, так что `API_BASE` должен быть пустым — поверх `js/env.js`
монтируется `js/env.docker.js` с `export const API_BASE = ''`. Генератор для этого режима
запускать не нужно, и на чистом клоне всё работает без него. CORS в этой схеме не
задействован: запросы same-origin, preflight не отправляется.

Rate-limit `10r/s`, `burst=20`, ответ `429` навешан **только** на `location /api/` — статику
он ограничивать не должен, одна страница тянет три десятка файлов и упёрлась бы в лимит.
`429` фронт уже обрабатывает («Забагато запитів»).

Параметр `?static` в адресе выключает анимации (то же, что системное «уменьшить движение»).
Двойным кликом по `index.html` открывать нельзя: ES-модули с `file://` блокируются.

## Контракт с бэкендом (сверено с `backend/app`, коммит «Extend error handling and fix some bugs»)

Единственный запрос фронта:

```
POST {api-base}/api/v1/contact
Content-Type: application/json

{
  "contact": "name@company.com",     // email | телефон | @telegram, ≤254 — бэк сам определяет тип
  "comment": "Позиція: …\nСторінка: /products.html#oth-motors\n\n<текст>"   // ≤4000
}
```

Форма минимальная: контакт и сообщение (поля «Имя» и «Компания» убраны в коммите
«Change contact form»). Всё, что есть сверх контракта — позиция из каталога и адрес
страницы — фронт упаковывает в `comment` строками `Ключ: значение`, дальше пустая
строка и текст сообщения.

Ошибки бэк отдаёт как RFC 7807 `application/problem+json`:

```json
{ "type": ".../problems/invalid-contact", "title": "Invalid Contact", "status": 422,
  "detail": "Use phone number, email or telegram (@username)", "instance": "/api/v1/contact",
  "timestamp": "…", "field": "contact" }
```
и для pydantic-ошибок — `type: …/validation-error`, `detail` на украинском, `errors: [{field, message, type}]`.

| Ответ | Что делает фронт |
|-------|------------------|
| `200 {"status":"ok","contact_type":"email\|phone\|telegram"}` | «Ваш запит на email / telegram / мобільний телефон надіслано», форма очищается. Неизвестный или отсутствующий `contact_type` → общее «Заявку надіслано» |
| `422` с `field: "contact"` или `type …/invalid-contact` | своё сообщение «Вкажіть email, телефон або @telegram», фокус на поле «Контакт» (английский `detail` не показывается) |
| `422` validation-error | показывает `detail` (он на украинском), фокус на поле из `errors[0].field` |
| `429` | «Забагато запитів» (на будущее, rate-limit у бэка пока нет) |
| другое / сеть | «Не вдалося надіслати», предлагает написать на почту |

Health-check: `GET {api-base}/api/v1/health` → `{"status":"ok"}`.
Поле-ловушка для ботов `website` на бэк не уходит.

### Если бэк будет отдавать фронт сам

Роуты API регистрировать **до** монтирования статики, иначе `/api/*` перехватит StaticFiles:

```python
from fastapi.staticfiles import StaticFiles
# ...после app.include_router(api_router, prefix=settings.api_prefix)
app.mount("/", StaticFiles(directory="../frontend", html=True), name="frontend")
```

## Ассортимент: данные и спецификации

`js/data/products.js` — MAIN (основные позиции: визуал, назначение, список названий и марок) и OTHER (остальные позиции: название + марка по категориям); сгенерированы из таблицы
`Desktop\Техдокументація — аксесуари+дрон lirun 2608\аксесуари+дрон lirun 2608 — статус техдокументації.xlsx`
(163 позиции, категории по блокам таблицы). Поле `doc` (yes/analog/no) в UI не показывается.

`js/data/specs.js` — объект `SPECS[id] = { desc, specs: [{k, v}], note, src, from }`:
- `from: "doc"` — параметры извлечены из документации постачальника в папке выше (каждый документ
  обработан агентом-экстрактором и независимо перепроверен вторым агентом по источнику);
  `src` — название документа; `note` — пометка, если документ на близкую модель (аналог);
- `from: "name"` — базовые параметры, выведенные из названия позиции (для позиций без документации).

`js/data/own.js` — позиции собственного производства (id 901+): звій G.657.A2 и пропеллеры
10″/15″, спецификации из презентации катушки и оффера. Категория «Власне виробництво PANCORE»
показывается первой.

## Карта мира

`js/data/worldmap.js` — суходол как один `<path>` (5,7 тыс. точек, эквиректангулярная проекция,
lon −170…180, lat −56…78; сгенерировано из `countries.geo.json`, johan/world.geo.json, public domain)
и координаты узлов. Маршруты и типы линий — `ROUTES` в `js/worldmap.js`
(`in` — компоненты в ЄС, `out` — готовая продукция, `world` — прочие). Анимации только
`stroke-dashoffset` и `transform`, без SVG-фильтров; включаются, когда карта в кадре.

## Производительность

- WebGL-фон рендерится с pixel ratio ≤ 1,25 (мобильные 1,0), без MSAA (рёбра сглаживаются
  в шейдере), сетка 36×22 + задний слой 60 %. Если средний кадр > 24 мс — pixel ratio
  автоматически снижается до 0,75.
- Рендер останавливается, когда герой ушёл за 1,6 экрана (главная) или полоса-герой вне кадра
  (внутренние страницы), и на скрытой вкладке.
- Зерно без `mix-blend-mode`, карта анимируется только в кадре, картинки `loading="lazy"`.

## Браузеры

Современные Chrome / Edge / Firefox / Safari (ES-модули, import maps, WebGL 1). Без WebGL
фон просто не рисуется — страница остаётся рабочей. `prefers-reduced-motion` уважается.
