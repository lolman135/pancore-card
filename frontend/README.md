# PANCORE — фронтенд

Статический сайт-визитка без сборки: три HTML-страницы, один CSS, ES-модули.
Никакого npm — открывается любым статическим сервером, а в проде отдаётся
бэкендом (FastAPI) как статика.

```
frontend/
├── index.html          главная: герой, о компании, направления, преимущества, контакты + форма
├── production.html     производство: оптоволокно, композиты, литьё, SMT, контроль качества
├── catalog.html        ассортимент: 163 позиции / 20 категорий, поиск, фильтры, форма запроса
├── css/style.css       дизайн-система (токены в :root)
├── js/site.js          общая логика: шапка, меню, появление блоков, WebGL-фон, форма → /api/contact
├── js/mesh.js          WebGL-поле граней (three.js, свои шейдеры) — ключевой визуальный элемент
├── js/catalog.js       логика страницы ассортимента
├── js/data/catalog.js  ДАННЫЕ ассортимента (сгенерированы из xlsx, см. ниже)
└── assets/             logo.svg, favicon.svg, img/*.webp (фото производства), img/carbon-m*.png (чертежи)
```

Язык сайта — украинский. Референс дизайна: тёмный графит + одна сигнальная красная,
триангулированная сетка на фоне (как в референсе владельца), шрифты Unbounded / Manrope /
JetBrains Mono / Michroma (Google Fonts). three.js подгружается с jsDelivr через import map.

## Локальный запуск

Любой статический сервер из папки `frontend/`:

```bash
py -m http.server 8090 --bind 127.0.0.1
```

и открыть <http://127.0.0.1:8090/>. Форма без бэкенда покажет честную ошибку
«Не вдалося надіслати» — «тихого» успеха специально нет.

Параметр `?static` в адресе выключает анимации (то же, что системное «уменьшить движение»).

## Контракт с бэкендом

Фронт делает один запрос:

```
POST /api/contact
Content-Type: application/json

{
  "name":    "Ім’я",                 // обязательно, 2–120 символов
  "email":   "name@company.com",     // обязательно, валидный e-mail
  "message": "текст",                // обязательно, 5–2000 символов
  "company": "Компанія",             // необязательно (только на главной)
  "item":    "назва позиції",        // необязательно (только на странице ассортимента)
  "page":    "/catalog.html#motors"  // откуда отправлено, служебное
}
```

Ожидаемые ответы:

| Код | Что делает фронт |
|-----|------------------|
| `200`/`201` | «Заявку надіслано», форма очищается |
| `422` | «Перевірте поля» + текст из `detail` (формат FastAPI/pydantic подходит как есть) |
| `429` | «Забагато запитів» (rate-limit) |
| другое / сеть | «Не вдалося надіслати», предлагает написать на почту |

Поле-ловушка для ботов `website` в JSON **не попадает** (фронт его вырезает); если бэкенд
всё же его получит — это бот, можно молча отвечать 200.

### Раздача статики из FastAPI

Роуты API регистрировать **до** монтирования статики, иначе `/api/*` перехватит StaticFiles:

```python
from fastapi import FastAPI
from fastapi.staticfiles import StaticFiles

app = FastAPI()

@app.post("/api/contact")
async def contact(lead: Lead): ...

app.mount("/", StaticFiles(directory="frontend", html=True), name="frontend")
```

Так фронт и API живут на одном origin — CORS не нужен, пути в коде относительные (`/api/contact`).
Если фронт будет на другом домене (Netlify/nginx), нужно (1) включить CORS на бэке для этого
домена и (2) заменить `'/api/contact'` в `js/site.js` на абсолютный URL API.

## Что заменить перед выкладкой (заглушки)

- `info@pancore.tech` — почта в шапке, футере и контактах (все три страницы). Телефона нет намеренно.
- Домен/canonical/OG-теги — добавить, когда известен домен.
- Логотип: `assets/logo.svg` перерисован по растровому оригиналу; при наличии вектора — заменить
  файл и `<symbol id="pc-logo">` в начале каждой страницы.
- Статус «Лінія в стадії запуску · 2026» (композиты) и «Проєкт у реалізації» (SMT) — обновлять по факту.

## Ассортимент: откуда данные и как обновлять

`js/data/catalog.js` сгенерирован из таблицы
`Desktop\Техдокументація — аксесуари+дрон lirun 2608\аксесуари+дрон lirun 2608 — статус техдокументації.xlsx`
(163 позиции; `doc: yes / analog / no` = «Є / Є аналог / Немає» из колонки C). Названия
приведены к читаемому виду (убраны артефакты машинного перевода), категории назначены по блокам таблицы.

Формат записи:

```js
{ id: 68, cat: "motors", name: "Двигун 3115 640KV/900KV/1050KV", brand: "", doc: "yes" }
```

Когда появится `GET /api/products`, достаточно отдавать массив того же вида — `catalog.js`
можно переключить с импорта на `fetch` без изменения разметки.

## Браузеры

Современные Chrome / Edge / Firefox / Safari (ES-модули, import maps, WebGL 1). Без WebGL
фон просто не рисуется — страница остаётся рабочей. `prefers-reduced-motion` уважается.
