# PANCORE — фронтенд

Статический сайт без сборки: три HTML-страницы, один CSS, ES-модули.
Никакого npm — открывается любым статическим сервером; в проде отдаётся
nginx/Netlify/любой статикой или бэкендом через `StaticFiles`.

```
frontend/
├── index.html          главная: герой, о компании, направления, преимущества, ассортимент, контакты + форма
├── production.html     производство: оптоволокно, композиты, литьё, SMT, контроль качества
├── catalog.html        ассортимент: 163 позиции / 20 категорий, поиск, фильтры, форма запроса
├── css/style.css       дизайн-система (токены в :root)
├── js/site.js          общая логика: шапка, меню, появление блоков, WebGL-фон, форма → API
├── js/mesh.js          WebGL-поле граней (three.js, свои шейдеры) — ключевой визуальный элемент
├── js/catalog.js       логика страницы ассортимента
├── js/data/catalog.js  ДАННЫЕ ассортимента (сгенерированы из xlsx, см. ниже)
└── assets/             logo.svg, favicon.svg, img/*.webp (фото производства), img/carbon-m*.png (чертежи)
```

Язык сайта — украинский. Дизайн: тёмный графит + одна сигнальная красная,
триангулированная сетка на фоне (референс владельца), шрифты Unbounded / Manrope /
JetBrains Mono / Michroma (Google Fonts). three.js подгружается с jsDelivr через import map.

## Локальный запуск

Фронт — любой статический сервер из папки `frontend/`:

```bash
py -m http.server 8090 --bind 127.0.0.1
```

Бэк — из папки `backend/` (см. `backend/`):

```bash
py -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe -m uvicorn main:app --reload --port 8000
```

Фронт и бэк на разных портах → в `<meta name="api-base">` каждой страницы поставить
`http://127.0.0.1:8000` (CORS у бэка по умолчанию `*`). Пусто = тот же origin.

Параметр `?static` в адресе выключает анимации (то же, что системное «уменьшить движение»).

## Контракт с бэкендом (сверено с `backend/app`, коммит «Add FastAPI Backend»)

Единственный запрос фронта:

```
POST {api-base}/api/v1/contact
Content-Type: application/json

{
  "contact": "name@company.com",     // email | телефон | @telegram, ≤254 — bэк сам определяет тип
  "comment": "Ім’я: …\nКомпанія: …\nПозиція: …\nСторінка: /catalog.html#motors\n\n<текст>"   // ≤4000
}
```

Поля формы (имя, компания, позиция из каталога, страница) фронт упаковывает в `comment`
строками `Ключ: значение`, дальше пустая строка и текст сообщения — так бэку не нужны
новые поля, а в JSONL/уведомлении видно всё.

| Ответ | Что делает фронт |
|-------|------------------|
| `200 {"status":"ok","contact_type":"email\|phone\|telegram"}` | «Заявку надіслано», форма очищается |
| `422 {"detail":"Укажите телефон, email или телеграм (@username)"}` | показывает `detail`, фокус на поле «Контакт» |
| `422` pydantic (список в `detail`) | склеивает `msg` через «; » |
| `429` | «Забагато запитів» (на будущее, сейчас у бэка нет rate-limit) |
| другое / сеть | «Не вдалося надіслати», предлагает написать на почту |

Health-check: `GET {api-base}/api/v1/health` → `{"status":"ok"}`.

Поле-ловушка для ботов `website` на бэк **не уходит** (фронт молча показывает «отправлено»).

Где база API: `<meta name="api-base" content="">` в `<head>` каждой страницы
(`js/site.js` читает её один раз при загрузке). Хвостовой `/` обрезается.

### Если бэк будет отдавать фронт сам

Роуты API регистрировать **до** монтирования статики, иначе `/api/*` перехватит StaticFiles:

```python
from fastapi.staticfiles import StaticFiles
# ...после app.include_router(api_router, prefix=settings.api_prefix)
app.mount("/", StaticFiles(directory="../frontend", html=True), name="frontend")
```

Тогда `api-base` остаётся пустым и CORS не нужен.

## Что заменить перед выкладкой (заглушки)

- `info@pancore.tech` — почта в контактах и футере (все три страницы). Телефона нет намеренно.
- Домен/canonical/OG-теги — добавить, когда известен домен.
- Логотип: `assets/logo.svg` перерисован по растровому оригиналу; при наличии вектора — заменить
  файл и `<symbol id="pc-logo">` в начале каждой страницы.
- Статусы «Лінія в стадії запуску · 2026» (композиты) и «Проєкт у реалізації» (SMT) — обновлять по факту.
- Нотификатор у бэка пока мок (пишет в лог) — заявки копятся в `backend/data/contacts.jsonl`.

## Ассортимент: откуда данные и как обновлять

`js/data/catalog.js` сгенерирован из таблицы
`Desktop\Техдокументація — аксесуари+дрон lirun 2608\аксесуари+дрон lirun 2608 — статус техдокументації.xlsx`
(163 позиции; `doc: yes / analog / no` = «Є / Є аналог / Немає» из колонки C). Названия
приведены к читаемому виду (убраны артефакты машинного перевода), категории назначены по блокам таблицы.

Формат записи:

```js
{ id: 68, cat: "motors", name: "Двигун 3115 640KV/900KV/1050KV", brand: "", doc: "yes" }
```

Когда появится `GET /api/v1/products`, достаточно отдавать массив того же вида — `catalog.js`
можно переключить с импорта на `fetch` без изменения разметки.

## Браузеры

Современные Chrome / Edge / Firefox / Safari (ES-модули, import maps, WebGL 1). Без WebGL
фон просто не рисуется — страница остаётся рабочей. `prefers-reduced-motion` уважается.
